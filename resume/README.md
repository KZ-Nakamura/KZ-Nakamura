## Projects at Findy

### 1. UserShare自動作成

#### Overview

Userとの面談後にエージェントが作成するユーザー情報サマリーである UserShare を、フォーム入力とスキルシートの生成AI読み込みによって自動作成する仕組みを設計・推進しました。

従来はOperatorが非構造な情報を整理し、業務上必要な形式にまとめる負荷がありました。そこで、入力情報の構造化、生成AIによる読み取り、確認・修正を前提としたHuman-in-the-loopな業務フローを組み合わせ、業務支援として機能する設計にしました。

#### Responsibilities

- 業務フロー整理
- 入力項目設計
- 非構造情報の構造化方針設計
- 生成AIを活用した情報抽出・要約フローの設計
- Operatorによる確認・修正を含むHuman-in-the-loop設計
- 業務利用に耐える出力形式の整理

#### Outcomes

- Operator入力負荷の削減
- 情報共有フォーマットの標準化
- 面談後オペレーションの効率化
- User情報の再利用性向上
- AIを単体機能ではなく、業務フローに組み込む形で活用

### 2. 業務UIのActiveAdminから内製UIへの移行

#### Overview

既存の業務UIをActiveAdminから内製UIへ移行し、UI移行にあわせてOpsフローも見直しました。

単純な画面置き換えではなく、Operatorが業務状態を把握しやすく、次のアクションを取りやすい状態を目指して、業務状態管理とUIの整合性を改善しました。

#### Responsibilities

- 既存業務フローの整理
- ActiveAdmin上で行われていた操作の棚卸し
- 内製UIに移行する対象機能の整理
- Operator UXの改善方針策定
- 業務状態と画面表示の整合性設計
- エンジニアとの仕様調整

#### Outcomes

- Operator UXの改善
- 業務状態管理とUIの整合性改善
- 業務フローに沿った操作体験の設計
- 今後の改善を進めやすい内製UI基盤への移行

### 3. UserUI - AdminUI のデータフロー統合

#### Overview

ユーザーアクションとOperatorアクションをシームレスに結合するため、UserUIとAdminUI間のデータフロー統合を推進しました。

ユーザー、Operator、Systemの間で情報が分断されると、業務効率や推薦品質に影響します。そのため、各アクションが自然につながり、業務上必要な情報が適切なタイミングで扱える状態を目指しました。

#### Responsibilities

- User / Operator / System 間のデータフロー整理
- ユーザーアクションとOperatorアクションの接続設計
- 業務状態の管理方針整理
- 推薦オペレーションに必要なデータ項目の整理
- プロダクト仕様の設計・調整

#### Outcomes

- User / Operator / System 間のデータ接続改善
- ユーザーアクションと業務オペレーションの連続性向上
- 推薦オペレーションの改善
- ユーザー推薦数 YoY 90% 成長に寄与
